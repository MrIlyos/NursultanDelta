# Nursultan Delta — Minecraft 1.8.9

Лёгкая основа клиентского Forge-мода для одиночной игры: ClickGUI, HUD и сохранение локальных настроек.

## Как получить JAR без сборки на своём ПК
1. Открой вкладку **Actions** этого репозитория.
2. Выбери workflow **Build Minecraft Forge 1.8.9 mod**.
3. Нажми **Run workflow** (или дождись автоматического запуска после push).
4. Открой успешный запуск и скачай артефакт **NursultanDelta-1.8.9**.
5. Распакуй архив артефакта. Помести JAR в папку `mods` профиля Minecraft Forge 1.8.9.

## Управление
- **Right Shift** — открыть ClickGUI.
- **ЛКМ** на модуле — включить/выключить.
- HUD отображает название клиента и FPS.
- Настройки хранятся в `config/nursultan-delta.properties`.

## Разработка
Проект использует ForgeGradle 2.1, Java 8 и Minecraft Forge 1.8.9. Из-за возраста инструментов сборка может потребовать правок совместимости. Первая сборка через GitHub Actions служит проверкой окружения.

Это стартовый проект, не готовый коммерческий клиент. Текущая реализация содержит HUD и базовое меню; дополнительные модули ещё предстоит реализовать.
